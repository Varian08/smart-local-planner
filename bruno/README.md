# Bruno API Collection — Smart Local Planner

> **Công cụ:** [Bruno](https://www.usebruno.com/) (Open-Source API Client, lưu trữ dạng file text thuần trong Git)  
> **Lợi ích:** Không cần tạo tài khoản Cloud, không lo lộ bí mật, version control trực tiếp cùng mã nguồn dự án.

---

## 🛠️ Hướng dẫn Sử dụng cho Thành viên

1. **Cài đặt Bruno:** Tải miễn phí tại [https://www.usebruno.com/downloads](https://www.usebruno.com/downloads).
2. **Mở Collection:**
   - Mở phần mềm Bruno ➔ Chọn **Open Collection**.
   - Trỏ tới thư mục `smart-local-planner/bruno/`.
3. **Thực thi kiểm thử:**
   - Đảm bảo Backend Spring Boot đang chạy tại `http://localhost:8080`.
   - Chọn request `Healthcheck` hoặc `Swagger-Docs` ➔ Bấm **Send** để kiểm tra phản hồi tức thì (`200 OK`).
